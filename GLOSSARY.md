# SourceGit

Git repository browsing and local history editing.

## Language

**Commit (提交)**: A recorded repository snapshot with a message, authorship and parent commits. A node in the history graph represents a commit.

**Squash (压缩提交)**: Replace consecutive commits on the current branch with one commit containing their combined changes and a chosen message.

**Recovery reference (恢复引用)**: A named reference retaining the branch's original tip before history is rewritten.

**Table preview (表格预览)**: A read-only view of one file version as rows and columns, distinct from comparing changes between versions.

**Cell difference (单元格差异)**: The added, deleted or changed stored values between two versions of a table, after matching their rows.

**Key column (关键列)**: A column whose nonempty, unique values identify corresponding rows across table versions, independent of their positions.
